# Project working preferences

- Minimise credit cost. Use Luna, Terra, or Sol for routine implementation, batch work, and simple checks. Prefer one focused delegation over overlapping agents.
- Use Astra for major architectural decisions, large-scale reasoning, and project-wide review.
- Delegate concrete implementation tasks when useful under this model split; provide enough context to avoid repeated exploration.
- Follow CONTRIBUTING.md and preserve existing saved recipes, backups, and machine assignments when extending the data model.
